# ImageMediaViewer アーキテクチャ概要

本書は、ImageMediaViewer のシステム構成および技術選定の経緯を記録する概要ドキュメントです。詳細な内部設計・スキーマ・IPC仕様については **[システム設計書 (docs/DESIGN.md)](DESIGN.md)** を参照してください。

---

## 1. システム全体構成

ImageMediaViewer は、**フロントエンド（React 18 + TypeScript + Tailwind CSS）** と **ネイティブエンジン（Rust + SQLite）** が同一プロセス内で一体化されたポートレス・ネイティブアプリケーションです。

```text
+---------------------------------------------------------------------------------+
|                               [ ユーザーインターフェース ]                         |
|                                                                                 |
|   【ネイティブデスクトップ】 (Tauri v2 / WebView2)   ／  【モバイル】 (Android)     |
|                                                                                 |
|   +-------------------------------------------------------------------------+   |
|   | フロントエンド (React 18 + TypeScript + Tailwind CSS)                    |   |
|   | - 仮想スクロールタイムライン (@tanstack/react-virtual, スケール圧縮対応)   |   |
|   | - 共有ページキャッシュ (SharedPageCacheManager, 世代同期)                |   |
|   | - 全画面ビューア (原寸バイキュービック, ズーム, パン, 等倍 1:1)           |   |
|   | - ムードボード (無限キャンバス, メモ付箋, 自動並び替え, LOD制御)          |   |
|   | - 監視フォルダ管理サイドバー / イベント駆動プログレスステータスバー      |   |
|   +-------------------------------------------------------------------------+   |
+----------------------------------------|----------------------------------------+
                                         | Tauri Native IPC & カスタムプロトコル (thumb://, original://)
                                         | ※ TCP/IP ポート不使用 (ポート競合ゼロ)
                                         v
+---------------------------------------------------------------------------------+
|                      [ 高速ネイティブエンジン (Rust) ]                            |
|                                                                                 |
|   +-------------------------------------------------------------------------+   |
|   | Native IPC & プロトコルハンドラ (src-tauri/src/protocol.rs, commands.rs)|   |
|   | - ゼロコピー WebP サムネイル配信 (thumb://<id>?v=<rev>)                 |   |
|   | - 原寸画像直接ストリーミング (original://<id>?v=<rev>)                   |   |
|   | - タスクトレイ常駐制御 (#[cfg(desktop)] tauri-plugin-single-instance)   |   |
|   +-------------------------------------------------------------------------+   |
|   | カタログDBマネージャ (SQLite WALモード, PRAGMA, Migration v7)            |   |
|   +-------------------------------------------------------------------------+   |
|   | サムネイル専用DB (thumbnails.db, WITHOUT ROWID, mmap 256MB)              |   |
|   +-------------------------------------------------------------------------+   |
|   | サムネイル生成パイプライン (CPU並列, 256MB メモリ予算セマフォ制御)       |   |
|   +-------------------------------------------------------------------------+   |
|   | ディレクトリ走査・差分インデクサー (File::open 1回化, blake3 quick_hash) |   |
|   +-------------------------------------------------------------------------+   |
|   | 安全設計: 元画像ファイルへの書き込み・変更・削除を行わない保護               |   |
+---------------------------------------------------------------------------------+
```

## 2. アーキテクチャの進化と技術選定

### 2.1 ポートレス一体型 Tauri v2 ネイティブへの統合
- **初期プロトタイプでの課題**:
  - 初期のクライアント・サーバー分離構成（HTTP ポート 14201）では、ローカルポートの競合、ファイアウォール警告ダイアログの表示、起動プロセスの多重管理などの運用課題が存在した。
  - また、かつて検討された Chromium 同梱方式（Electron 等）では、インストーラー容量が 150MB を超え、メモリフットプリントが肥大化する問題があった。
- **採用された解決策**:
  - Tauri v2 による **ポートレス一体型アーキテクチャ** を採用。
  - TCP/IP ポートを開かず、プロセス内 IPC（Tauri `invoke`）およびカスタムプロトコルハンドラ（`thumb://`, `original://`）によって通信を完結。
  - OS ネイティブの WebView（Windows: WebView2, macOS: WebKit, Linux: WebKitGTK, Android: WebView）を活用することで、インストーラー容量約 24MB、アイドル時メモリ 150MB 以下という軽量性を実現。

### 2.2 クロスプラットフォーム両対応 (Desktop & Mobile)
- **デスクトップ**: Windows 10/11, macOS, Linux に対応。タスクトレイ常駐、二重起動抑止（`tauri-plugin-single-instance`）、NSIS インストーラーをサポート。
- **モバイル**: Android 10+ (API 29+)、主要対象 Android 13+ (API 33+) に対応。Android 13+ の細分化メディア権限（`READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO`）、システム戻るボタンの階層連動ナビゲーション、スライドイン式ドロワー、セーフエリア自動回避を標準実装。

### 2.3 高速 Rust コアエンジンの性能
- **検証済み性能**:
  - 10万件ダミーデータ投入: 95,085 件/秒
  - タイムラインサマリ集計: 57.23 ms (1,002日分)
  - ページング取得: 3.07 ms (OFFSET 50,000 件地点)
  - 元ファイル不変性: テスト（`pipeline_test.rs`）にて検証済み。

## 3. 起動・ビルド方法

### デスクトップアプリの起動:
```cmd
# Windows (ランチャー実行)
run.bat
```

### 開発モード起動:
```bash
# フロントエンド + バックエンド同時起動
npm run tauri dev
```

### ビルド:
```bash
# Windows インストーラー (NSIS セットアップ EXE)
npm run build:installer

# Android APK (Release)
npm run build:android:release
```
