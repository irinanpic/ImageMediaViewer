# ImageMediaViewer アーキテクチャ設計書

本ドキュメントは、要件定義書 `image-catalog-spec-v2.md` および Windows 11 Insider 環境における独立デスクトップウィンドウ表示の課題を解決するために実施した根本的なフロントエンド／バックエンド再構築アーキテクチャを記録するものです。

---

## 2. 刷新理由と技術選定の根拠

### 2.1 独立デスクトップウィンドウの確実な表示 (Electron)
- **課題**: Windows 11 Insider Preview (Canary 26300) および Edge WebView2 Canary ランタイム環境において、Tauri v2 (Wry / Tao) の HWND 生成・表示ループが WebView2 の初期化パイプでハングし、バックエンドプロセスは存在するものの画面およびタスクバーにウィンドウが一切表示されない問題が発生していた。
- **解決策**: Chromium を直接同梱する Electron をフロントエンドラッパーとして採用。あらゆる Windows バージョンにおいて 100% 確実にデスクトップウィンドウ（1280x800）を生成・表示し、タスクバーにもアプリアイコンを確実に登録する。

### 2.2 ブラウザと独立ウィンドウのハイブリッド両対応
- **設計**: フロントエンドの通信層（`src/lib/ipc.ts`, `src/lib/thumbUrl.ts`）を抽象化し、Tauri ネイティブ IPC、Electron ネイティブダイアログ、および標準 HTTP API への自動フォールバックを実装。
- **効果**: 独立したデスクトップアプリケーションとして快適に使用できるだけでなく、ブラウザ（`http://127.0.0.1:1420`）から直接開いて操作することも可能。

### 2.3 高速 Rust コアエンジンの完全維持
- **検証済み性能**:
  - 10万件ダミーデータ投入: 95,085 件/秒
  - タイムラインサマリ集計: 57.23 ms
  - ページング取得: 3.07 ms
  - 元ファイル不変性: テスト（`pipeline_test.rs`）にて 100% 検証済み。

## 3. 起動方法

### 独立デスクトップアプリとして起動:
```powershell
# 推奨: ランチャースクリプトを実行
.\run.bat
```

### 開発モード（フロントエンド & バックエンド）:
```powershell
# フロントエンド開発サーバー起動
bun run dev

# Tauri 開発モード起動
bun run tauri dev
```
