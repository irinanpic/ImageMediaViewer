# ImageMediaViewer ユーザマニュアル (User Manual)

軽量・高速クロスプラットフォーム画像カタログ＆メディアビューア **ImageMediaViewer** の操作マニュアルです。

---

## 1. はじめに

ImageMediaViewer は、PC 内の複数の写真フォルダを登録し、撮影日時の時系列（タイムライン）でまとめて高速に閲覧・整理できる画像ビューアです。

### 🌟 主な特徴
* **圧倒的な高速スクロール**: 何万枚もの写真があっても、カクつかず滑らかに閲覧できます。
* **元画像ファイルの完全保護 (非破壊)**: 写真の書き換え、移動、削除は一切行いません。安心して大量の写真を登録できます。
* **Picasa スタイルのスクロールバー**: 目的の年月にドラッグで一瞬でジャンプできます。
* **しおり（ブックマーク）機能**: よく見る日付やアルバムの位置を名前をつけて保存し、いつでもワンクリックで復帰できます。
* **ムードボード (自由配置キャンバス)**: 写真を自由に並べ替え、コラージュを作成。矩形切り抜きやレイヤー重なり順の調整も可能です。

---

## 2. 起動方法

### 通常の起動方法（画面＋サーバー）
* **Windows**:
  * プロジェクトフォルダ内の **`run.bat`** または **`run.ps1`** をダブルクリックして実行します。
  * 自動的にバックエンドサーバーが起動し、デスクトップ上に ImageMediaViewer のアプリウィンドウが表示されます。
* **macOS / Linux**:
  * ターミナルから `./run-server.sh` を実行してサーバーを起動し、ブラウザで `http://localhost:14201` を開きます。

### サーバーのみバックグラウンド常駐起動（画面を開かない）
タスクトレイに常駐させたい場合や、通信途絶後にサーバーのみを再開させたい場合は、専用のサーバーランチャーを使用します（既に起動中の場合は二重起動しません）。
* **Windows**: **`run-server.bat`** をダブルクリック（またはコマンド実行）
* **macOS / Linux**: ターミナルで **`./run-server.sh`** を実行

> [!TIP]
> Google Chrome や Microsoft Edge などのWebブラウザから利用したい場合は、ブラウザのアドレスバーに以下を入力して開くこともできます。
> ```text
> http://127.0.0.1:14201
> ```

## 4. 基本操作ガイド

### 4.1 写真フォルダの追加と整理
1. **フォルダの追加**:
   * Windows エクスプローラーから写真が入ったフォルダを、画面左側のサイドバーへ直接 **ドラッグ＆ドロップ** します。
   * またはサイドバー上部の **「＋ 追加」** ボタンをクリックしてフォルダを選択します。
2. **フォルダの並び替え**:
   * サイドバーのフォルダ一覧で、フォルダ名の左側にあるグリップアイコン（`⋮⋮`）をドラッグして、お好みの順序に並び替えられます。
3. **フォルダの登録解除**:
   * フォルダ名にマウスカーソルを合わせると右側に表示されるゴミ箱アイコンをクリックします。
   * ※ 登録解除しても、**PC内の元画像ファイルは絶対に削除されません**。

### 4.2 タイムラインの閲覧と表示サイズ変更
* **スクロール**: マウスホイールで上下にスクロールします。
* **表示サイズの変更 (ズーム)**:
   * 下部ステータスバー右側の **ズームスライダー** を動かすか、スライダー上でマウスホイールを回転させると、サムネイルの大きさを 80px 〜 320px の範囲で自由に変更できます。
   * また、グリッド上で `Ctrl` キーを押しながらマウスホイールを回転させることでもズーム操作が可能です。
   * 冗長性を排除するため、上部やグリッド内の重複スライダーはステータスバーへ一本化されています。

### 4.3 高速スクロールバー (スクラブバー)
画面の右端にある縦型のバーは、Picasa スタイルの高速スクラバーです。
* バー上をマウスでドラッグすると、過去数年分の写真を一気に駆け抜けることができます。
* つまみを動かしている間、左側に **「該当日付」** と **「通し枚数」** がリアルタイムで表示されます。

### 4.4 しおり（ブックマーク）機能
「あの旅行の日の写真」「未整理の写真の位置」などを記録できます。
1. **しおりを挟む**:
   * タイムライン上部のツールバーにある **「🔖 しおり」** ボタンをクリックします。
   * 「現在の位置をしおりに追加」をクリックし、好きな名前（例: 「2024年 沖縄旅行」）を入力して「保存」を押します。
2. **しおりの位置へジャンプ**:
   * 「🔖 しおり」ボタンをクリックし、一覧から行きたいしおりをクリックすると、別フォルダや別ソート順であっても一瞬でその場所へジャンプします。
3. **しおりの削除**:
   * しおり一覧のゴミ箱アイコンをクリックして削除できます。

### 4.5 ソート順の変更
ツールバーのソート切り替えメニューから、以下の並び順を選択できます：
* **撮影日時（新しい順）** [推奨]
* **撮影日時（古い順）**
* **登録フォルダ順** (フォルダごとにまとまって表示されるPicasaスタイル)
* **ファイル名（A → Z）**
* **ファイル名（Z → A）**

## 5. 写真の拡大表示（詳細ビューア）

タイムライン上の写真を **左クリック** すると、全画面ビューアが開きます。

### 5.1 ビューアでの操作
| 操作 | キー / マウス | 動作説明 |
| :--- | :--- | :--- |
| **閉じる** | `Esc` または画面右上の `✕` | タイムラインの直前位置へ復帰します |
| **前後送り** | `←` / `→` キー、または左右矢印ボタン | 前の写真 / 次の写真へ移動します |
| **拡大・縮小** | マウスホイール / 画面下スライダー | 写真を無段階にズームイン・ズームアウトします |
| **パン (移動)** | 拡大時にドラッグ | 拡大表示した写真を自由に動かせます |
| **90度回転** | `R` キー / 時計回りボタン | 表示を90度回転します（非破壊） |
| **反転** | `H` キー (左右反転) / `V` キー (上下反転) | 水平・垂直に反転表示します（非破壊） |
| **詳細情報パネル** | 画面右上の `ℹ️` ボタン | 画像フォーマット、可逆/非可逆、圧縮率、撮影日時、解像度、実パスを表示します |
| **エクスプローラ表示**| 情報パネル内の「フォルダで表示」 | Windowsエクスプローラー等で実ファイルを選択表示します |

### 5.2 詳細情報パネルの見方
情報パネルでは、画像に関する技術的なメタデータが分かりやすく整理されています：
* **画像フォーマット**: JPEG, PNG, WebP, GIF, BMP 等の正式形式を表示。
* **可逆 / 非可逆 (Lossless / Lossy)**:
  * PNG / BMP / GIF 等: 画質の劣化がない「可逆圧縮 (Lossless)」
  * JPEG / 一部WebP 等: 人間の視覚特性を利用して大幅に容量を抑えた「非可逆圧縮 (Lossy)」
* **ファイルサイズ & 圧縮率**:
  * 実ファイルサイズと、非圧縮 24bit RGB 生データ（幅 × 高さ × 3バイト）との比較による「削減率 %」「生データ比 %」「bpp（1ピクセルあたりの実効ビット数）」を表示。
* **撮影日時 / 解像度 / パス**: EXIF 記録日時や画像本来のピクセル寸法、PC内の完全な保存場所を確認可能。

## 6. ムードボード（自由配置キャンバス）

複数の写真を1つのキャンバスに自由にレイアウトし、資料作成やアイデア整理ができる機能です。写真だけでなくテキストメモ（付箋）も自由に貼ることができます。

### 6.1 ボードの利用手順
1. **ボードへ切り替え**:
   * サイドバー上部の **「ムードボード」** タブをクリックします。
2. **写真の追加**:
   * タイムラインで写真を選択し、ツールバーの「ボードに追加」をクリックするか、ボード上で右クリックして写真を追加します。
3. **アイテムの配置と変形**:
   * **移動**: 写真をドラッグして好きな位置に動かします。
   * **回転・サイズ変更**: 写真の四隅をドラッグして拡大縮小、回転ハンドルで任意の角度に傾けられます。
4. **重なり順 (Z-Index) の変更**:
   * 写真やメモをクリックすると下部に表示されるアクションバー、またはショートカットキーでレイヤーの重なり順を変更できます。
   * `PageUp` / `]` : 前面へ
   * `PageDown` / `[` : 背面へ
   * `Shift + PageUp` : 最前面へ
   * `Shift + PageDown` : 最背面へ
5. **ドラッグ矩形クリッピング (切り抜き)**:
   * 写真を選択して **「✂ クリッピング (C)」** ボタンをクリックします。
   * 写真上をマウスドラッグすると四角い切り抜き枠（矩形）が描かれ、マウスを離すとその部分だけが切り抜かれて表示されます。
   * 元に戻したいときは **「リセット (R)」** を押すと全表示に戻ります。
6. **写真の反転**:
   * アクションバーの **「↔ 左右反転 (H)」** や **「↕ 上下反転 (V)」** でアイテム単位の反転が可能です。

### 6.2 写真の詳細情報表示
ムードボード上でも、選択した写真の詳しい情報をタイムラインと同じパネルで確認できます。
* **操作方法**: 写真をクリックして選択し、下部アクションバーの **「ℹ️ 詳細情報 (I)」** ボタンをクリックするか、キーボードの **`I`** キーを押します。
* **表示内容**: キャンバス右下にフローティングパネルが現れ、画像フォーマット、可逆/非可逆、ファイルサイズ・圧縮率、解像度、保存先パスなどを確認できます。

### 6.3 テキストメモ機能（付箋メモ）
キャンバス上にアイデアやキャプション、注釈などのテキストメモを配置できます。
1. **メモの新規追加**:
   * ボード上部のヘッダーにある **「➕ 📝 メモを追加」** ボタンをクリックします。キャンバス中央に新しい付箋メモが追加されます。
2. **位置の移動とサイズ変更**:
   * メモの背景をドラッグすると、写真と同様に好きな場所へ移動できます。
   * メモの右下隅にあるリサイズハンドル（◢）をドラッグすると、縦横の大きさを自由に変更できます。
3. **テキストの入力・編集**:
   * メモを **ダブルクリック** するか、選択時に表示されるアクションバーの **「✏️ 編集」** ボタンをクリックするとテキスト入力欄が開きます。
   * キーボードで文字を入力し、**`Ctrl + Enter`**（または入力欄外をクリック）で保存確定します。キャンセルする場合は **`Esc`** キーを押します。
4. **カラーの変更**:
   * メモを選択した状態でアクションバーのカラーパレット（イエロー、ブルー、グリーン、ピンク、パープル、ダーク）をクリックすると、背景色が一瞬で切り替わります。
5. **ロック・重なり順・削除**:
   * 誤操作を防ぎたい場合は **「🔒 ロック」** をONにします。
   * 写真とメモは同じレイヤー階層を持つため、写真の上にメモを重ねたり、メモを写真の下に配置することも自由自在です。

## 7. サムネイルの生成状況確認と再作成

### 7.1 進捗バッジの見方
* **`✓ 完了 (45,829枚)`** (緑色バッジ):
  * すべての写真のサムネイルが生成済みで、即座に表示可能な状態です。
* **`⏳ 生成中 12,500/45,829`** (オレンジ色バッジ):
  * バックグラウンドでサムネイル生成が進んでいます。

### 7.2 未生成・失敗サムネイルの再作成
カメラのRAWファイルや巨大画像などでサムネイル生成が中断していた場合でも、以下の方法で自動・手動で再作成できます：
1. **自動生成**:
   * タイムラインをスクロールしてサムネイルのない写真が表示されると、**自動的に検知して最優先でサムネイル化**が行われます。
2. **手動一括再作成**:
   * サイドバーの各フォルダ名にマウスを合わせると表示される **「🔄（サムネイル再作成）」** アイコンをクリックします。
   * バックグラウンドで残りの未生成画像が高速パイプライン（EXIF内蔵サムネイル最優先抽出）により順次サムネイル化されます。

## 9. タスクトレイ常駐と通信状態の管理

### 9.1 タスクトレイ（システムトレイ）常駐
ImageMediaViewer のサーバーは、クライアントウィンドウの開閉に関わらずバックグラウンドで安定して常駐稼働できます。
* **トレイアイコンの表示**:
  * Windows（タスクトレイ通知領域）、macOS（上部メニューバー）、Linux（システムトレイ）にアプリアイコンが表示されます。
* **トレイアイコンの操作**:
  * **左クリック**: クライアント画面を即座に開きます。
  * **右クリックメニュー**:
    * **クライアントを開く**: 独立アプリウィンドウまたは既定ブラウザで画面を開きます。
    * **フォルダを再走査**: 登録済みフォルダの差分スキャンをバックグラウンドで開始します。
    * **データフォルダを開く**: カタログDBやキャッシュが保存されているフォルダをエクスプローラー等で開きます。
    * **終了**: サーバープロセスを完全に終了します。

### 9.2 通信状態の確認と再接続
画面上部のツールバー右側に、バックエンドサーバーとの通信状態がリアルタイムで表示されます。

| 表示 | 状態 | 内容 |
| :--- | :--- | :--- |
| **🟢 接続中** | 正常稼働 | サーバーと正常に通信しています。 |
| **🟡 接続確認中...** | 通信試行 | サーバーへ接続を確認しています。 |
| **🔴 サーバー切断** | 通信途絶 | サーバーが停止しているか、通信が途絶しています。 |

* **通信途絶時の再接続手順**:
  * 「🔴 サーバー切断」をクリックすると、詳細パネルが表示されます。
  * **「再接続を試行」**: サーバーへの接続確認を即座に再試行します。サーバーが再開すると、自動的に画面が最新状態へ復旧します。
  * **「サーバーを起動 (URI呼び出し)」**:
    * カスタムプロトコル（`imagemediaviewer://launch`）を呼び出し、バックグラウンドサーバーのみを起動します。
    * **クライアント画面は二重起動しません**。開いている現在の画面のまま数秒以内に自動再接続されます。
  * **起動コマンドのコピー**:
    * 閲覧しているOS（Windows / macOS / Linux）を自動判定し、最適なサーバー起動コマンド（Windows: `.\run-server.bat`、macOS/Linux: `./run-server.sh`）をワンクリックでコピーできます。ターミナル等で貼り付けて実行すればサーバーのみがバックグラウンド起動します。

### 9.3 システムログとエラー診断（サムネイル失敗確認）
サムネイルの生成が進まない場合や、特定の画像でエラーが発生した場合の確認機能です。

* **ログモーダルの開き方**:
  * 下部ステータスバーの右側にある **「ログ」** ボタンをクリックします。
  * サムネイル生成で失敗した画像がある場合は、ステータスバーに **「⚠️ サムネイル完了 (○件完了 / △件失敗)」** と表示され、ここをクリックしても開けます。
  * タスクトレイアイコンを右クリックして **「ログフォルダを開く」** を選ぶと、直接ログ保存先フォルダが開きます。
* **失敗画像一覧タブ**:
  * ファイル破損、0バイトの空ファイル、アニメーションWebP等の未対応形式でサムネイルが作れなかったファイルを一覧表示します。
  * 「表示」リンクをクリックすると、Windowsエクスプローラーでそのファイルが選択された状態で開きます。
  * 「失敗画像の再生成を試みる」ボタンで、未生成・失敗分の再スキャンを一括実行できます。
* **システムログタブ**:
  * バックエンドサーバーの直近ログをリアルタイムに確認できます（ERROR/WARN/INFO等）。
  * ログのコピーボタンで開発者への問い合わせ用テキストを一括取得できます。
* **ログファイルの実パス**:
  * `%APPDATA%\com.imagemediaviewer.app\logs\app.log`

## 9. よくある質問 (FAQ)

### Q. PC内の元画像ファイルが勝手に変更・削除される心配はありませんか？
**A. 一切ありません。**
ImageMediaViewer は完全な読み取り専用（Read-Only）設計です。ファイルの上書き保存、リネーム、移動、削除の処理ロジックそのものが存在しないため、安心して大切な写真ライブラリを登録していただけます。

### Q. サムネイル画像やデータベースはどこに保存されていますか？
* **サムネイルキャッシュDB**:
  `%LOCALAPPDATA%\com.imagemediaviewer.app\cache\thumbnails.db`
* **カタログデータベース (SQLite)**:
  `%APPDATA%\com.imagemediaviewer.app\catalog.db`
※ 不要になった場合は、上記フォルダを削除するだけで完全に初期化できます。

### Q. アプリのウィンドウを閉じると、サーバーも停止しますか？
**A. デフォルトではタスクトレイに常駐し、すぐに再開できます。**
ウィンドウを閉じても、サーバーはタスクトレイにアイコン表示された状態でバックグラウンド常駐します。タスクトレイアイコンを右クリックして「終了」を選ぶことで、いつでも完全にプロセスを終了できます。また、必要に応じて起動オプション `--auto-exit` を指定すれば、以前のようにウィンドウ終了に合わせてサーバーを自動停止させることも可能です。

### Q. サムネイル生成数が途中で止まって進まなくなりました（例: 46707 / 46711）。
**A. ファイル破損や0バイトの空ファイル、アニメーション形式等の理由で、一部の画像が安全にスキップされた状態です。**
下部ステータスバーの「⚠️ サムネイル完了 (46,707件完了 / 4件失敗)」または「ログ」ボタンをクリックしてください。「失敗画像一覧」タブで該当ファイルのパスとサイズ（0バイト等）を確認できます。これらのファイルは安全のために除外されており、アプリのフリーズではありません。他の正常な画像はすべて高速に閲覧可能です。

### Q. 長時間(2時間など)放置したり、PCがスリープした後にサーバーが止まってしまうことはありませんか？
**A. 対策済みです。ブラウザの省電力機能による誤停止を防ぎ、安定して常駐し続けます。**
以前は、OSのスリープや画面オフ、ブラウザの「メモリセーバー（タブの休止）」に伴う `pagehide` イベントにより、フロントエンドからシャットダウンリクエストが誤送信されて停止してしまう問題がありました。
最新バージョンではこの誤シャットダウン処理を完全に撤廃し、常駐モード時は明示的にトレイメニューから「終了」を選ばない限りサーバープロセスが終了しないよう保護されています。

### Q. 通信が切断された場合、どのように回復できますか？またクライアント画面が多重起動しませんか？
**A. 画面右上の切断インジケータからワンクリックでサーバーのみを安全に再起動・回復できます。多重起動はしません。**
1. 画面右上の **「🔴 サーバー切断」** をクリックします。
2. 表示されたパネルで **「サーバーを起動 (URI呼び出し)」** をクリックしてください。
3. サーバー専用ランチャー（`run-server.bat`）が呼び出され、**クライアント画面は二重起動せず、サーバープロセスのみがバックグラウンド起動** します。
4. 起動後、画面が自動的に再接続を試行し、数秒で元の閲覧状態に復帰します。
※ 他のOS（macOS / Linux）をご利用の場合や手動で起動したい場合も、同パネルにOSに合わせた起動コマンド（`.\run-server.bat` または `./run-server.sh`）が表示されますので、コピーしてターミナルで実行するだけで回復できます。
