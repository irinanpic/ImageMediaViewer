# ImageMediaViewer

かつての「Picasa」が持っていた「複数フォルダを跨いだ時系列・シームレスな高速画像閲覧体験」を、Rust + React + TypeScript + SQLite で実現した軽量クロスプラットフォーム画像カタログ＆メディアビューアです。

## 主な特徴

- **複数フォルダ横断タイムライン (F-01, F-05)**:
  - 任意の複数フォルダを監視対象として登録可能。
  - フォルダ構造の物理配置とアプリ上の論理表示（撮影日時降順タイムライン）を完全分離。
- **高速な差分走査パイプライン (F-02, F-03)**:
  - 初回走査後は `(path, size, mtime)` 比較による差分走査を行い、変更のないファイルは即座にスキップ。
  - `kamadak-exif` による Exif 解析（`DateTimeOriginal`、Orientation）および `imagesize` による高速ヘッダ寸法取得。
- **堅牢なサムネイル生成パイプライン (F-04)**:
  - 優先度付きキュー（画面内 HIGH / プリフェッチ MID / バックグラウンド LOW）。
  - メモリ予算（256MB）セマフォ制御により、巨大画像の同時デコードによるメモリ圧迫・クラッシュを防止。
  - `fast_image_resize` による高速リサイズと `webp` クレートによる品質75の lossy WebP 保存。
  - `.tmp` からの不可逆 rename によるアトミック保存。
- **60fps 目標の仮想スクロール (F-05, §8)**:
  - 日別件数サマリからレイアウト行高さを事前確定する `@tanstack/react-virtual` 仮想スクロール。
  - 200件単位のページング取得と LRU キャッシュ。
  - 超高速スクロール中（3,000px/s 超）の画像ロード自動抑制。
- **フル機能シングル画像ビューア (F-06, F-07, F-12)**:
  - サムネイル即時表示からの原寸画像非同期差し替え。
  - 前後移動（← / →）、閉じる（Esc）、右回転/左回転（R / Shift+R）、反転（H / V）、ズーム（ホイール / + / -）、フィット/等倍切替（0 / 1 / ダブルクリック）、パン（ドラッグ）。
  - 情報パネル（I）および OS ファイルマネージャ（エクスプローラ）連携。
- **完全な元ファイル保護・不変性 (§0-1, §2.3)**:
  - 元画像ファイルへの書き込み・移動・削除は一切行いません。ファイル書き込みはカタログDBとキャッシュのみに限定。
  - テストコードにて、走査・サムネイル生成前後で元ファイルのハッシュおよび mtime が不変であることを保証。
- **タスクトレイ常駐＆クロスプラットフォーム対応 (F-26)**:
  - サーバーはクライアントの開閉によらず、OSのタスクトレイ（Windows 通知領域、macOS メニューバー、Linux システムトレイ）にアイコン表示されて安定常駐。
  * トレイ右クリックから「クライアントを開く」「フォルダ再走査」「データフォルダを開く」「終了」を操作可能。
- **リアルタイム通信状態監視＆ワンクリック再接続 (F-27)**:
  - 画面上部右側に常時通信インジケータ（🟢 / 🟡 / 🔴）を表示し、途絶時は警告バッジおよび再接続・サーバー起動リンクを提供。
  - サムネイル拡大縮小バーはステータスバー（80px〜320px）へ一本化。

## 開発・ビルド手順

### 1. 依存関係のインストール

```bash
bun install
```

### 2. アプリケーションの起動

#### 方法 A: 独立デスクトップウィンドウとして起動（推奨）
プロジェクト直下の `run.bat` をダブルクリック（またはコマンドプロンプトから実行）します。
```cmd
run.bat
```
バックエンドサーバー（ポート 14201）が自動起動し、Edge または Chrome の App Mode を利用した専用の独立ウィンドウ（アドレスバーやタブのないアプリウィンドウ）が立ち上がります。

#### 方法 B: Webブラウザから直接利用
バックエンドサーバーが稼働している状態で、お好みのブラウザ（Chrome, Edge, Firefox 等）で以下を開きます：
```
http://127.0.0.1:14201/
```

#### 方法 C: 開発モード起動 (Tauri Dev)
```bash
bun run tauri dev
```


### 3. フロントエンドのビルド・型チェック

```bash
bun run build
```

### 4. ユニットテスト・統合テストの実行

#### フロントエンド単体テスト (Vitest)
```bash
bun run test
```

#### バックエンド単体・統合テスト (Rust)
```bash
cd src-tauri
cargo test
cargo test --test pipeline_test
```
