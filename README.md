# ImageMediaViewer

複数フォルダを跨いだ時系列・シームレスな高速画像閲覧体験を、Rust + React + TypeScript + SQLite で実現した軽量クロスプラットフォーム画像カタログ＆メディアビューアです。

## 主な特徴

- **複数フォルダ横断タイムライン (F-01, F-05)**:
  - 任意の複数フォルダを監視対象として登録可能。
  - フォルダ構造の物理配置とアプリ上の論理表示（撮影日時・登録フォルダ・ファイル名等）を分離してシームレスに一覧表示。
  - 縦型スクラブバーにより、大量の画像があっても目的の年月へ素早くスクロール移動。
- **高速な差分走査パイプライン (F-02, F-03)**:
  - 初回走査後は `(path, size, mtime)` 比較による差分走査を行い、変更のないファイルは即座にスキップ。
  - `kamadak-exif` による Exif 解析（`DateTimeOriginal`、Orientation）および `imagesize` による高速ヘッダ寸法取得。
- **堅牢なサムネイル生成パイプライン (F-04)**:
  - 優先度付きキュー（画面内 HIGH / プリフェッチ MID / バックグラウンド LOW）。
  - クイックハッシュによるキャッシュ共有により、同一内容の画像に対する重複サムネイル生成をスキップ。
  - メモリ予算（256MB）セマフォ制御により、巨大画像の同時デコードによるメモリ圧迫を防止。
  - `fast_image_resize` による高速リサイズと `webp` クレートによる品質75の lossy WebP 保存。
- **イベント駆動型プログレス通知 & 低負荷常駐**:
  - 定期ポーリングや不要なハートビートを廃止し、Rust側からのイベント通知（`scan:progress`, `thumb:progress`, `catalog:changed`）によるイベント駆動プログレス通知を実現。
  - アプリ常駐時やアイドル時のCPU負荷を極小化（実測 0%）。
- **スムーズな仮想スクロール (F-05, §8)**:
  - 日別件数サマリからレイアウト行高さを事前確定する `@tanstack/react-virtual` 仮想スクロール。
  - スケール圧縮アルゴリズムにより、同一行内でのアスペクト比極端差による過密境界やレイアウト崩れを自動補正。
  - 200件単位のページング取得と LRU キャッシュ。
  - 高速スクロール中（3,000px/s 超）の画像ロード自動抑制。
- **自由自在なムードボード (F-17〜F-25)**:
  - お気に入りの画像や資料をキャンバス上に自由配置・拡大・縮小・回転・クリッピング。
  - カラーラベル付きメモ（付箋）の配置・編集機能。
  - ズーム倍率に応じたLOD（詳細度）制御により、広域表示時も軽快に描画。
- **フル機能シングル画像ビューア (F-06, F-07, F-12)**:
  - サムネイル即時表示からの原寸画像非同期読み込み。
  - 原寸ピクセル等倍（1:1）表示と画面フィット表示をワンタッチで切り替え。
  - 前後移動（← / →）、閉じる（Esc）、右回転/左回転（R / Shift+R）、反転（H / V）、ズーム（ホイール / + / -）、パン（ドラッグ）。
  - 詳細情報パネル（I）および OS ファイルマネージャ（エクスプローラ）連携。
- **元ファイル保護・不変性設計 (§0-1, §2.3)**:
  - 元画像ファイルへの書き込み・移動・削除を行わない読み取り専用設計。ファイル書き込みはカタログDBとキャッシュのみに限定。
  - 自動テストにて、走査・サムネイル生成前後で元ファイルのハッシュおよび mtime が不変であることを検証済み。
- **タスクトレイ常駐＆クロスプラットフォーム対応 (F-26)**:
  - Windows / macOS / Linux / Android に対応。
  - デスクトップ版ではタスクトレイにアイコン表示されてバックグラウンド常駐可能。
  - Android 版では Android 13+ の最新メディア権限に対応し、システム戻るボタンの階層連動ナビゲーションをサポート。
- **安全なビルド環境**:
  - Windows環境特有のNTFS ReadOnly属性によるビルドエラーを防止する自動クリーンアップスクリプトをビルド工程に標準組み込み。

## 開発・ビルド手順

### 1. 依存関係のインストール

```bash
npm install
# または bun を使用する場合: bun install
```

### 2. アプリケーションの起動

#### デスクトップアプリの起動（推奨）
プロジェクト直下の `run.bat` をダブルクリック（またはコマンドプロンプトから実行）します。
```cmd
run.bat
```
* **ポート不使用の一体型アーキテクチャ**: TCP/IP ポート（14201 等）を開かず、Tauri 内部通信パイプにより連携するため、他のプログラムとのポート競合やファイアウォール警告が発生しません。
* **タスクトレイ常駐制御**:
  * メインウィンドウを閉じてもタスクトレイに残って常駐します（デフォルト ON）。
  * トレイアイコンをクリック（または「クライアントを開く」）ですぐに最前面に再表示されます。
  * トレイ右クリックメニューの **「常駐する」**（チェック項目）を OFF にすると、メインウィンドウを閉じた際にアプリ全体が終了します（この設定は自動保存されます）。
  * アプリを終了する場合は、トレイ右クリックメニューから **「終了」** を選択します。

#### 開発モード起動 (Tauri Dev)
```bash
npm run tauri dev
```


### 3. フロントエンドのビルド・型チェック

```bash
bun run build
# または npm を使用する場合
npm run build
```

### 4. インストーラー（インストール用ビルド）の作成

デスクトップアプリのインストーラー（Windows: NSIS セットアップ EXE）をビルドします：

```bash
npm run build:installer
```

※ ビルド開始時に自動的に `clean-target-readonly.mjs` が実行され、Windows NTFS の読み取り専用属性に起因するビルドエラーを未然に防止します。

ビルドが完了すると、`src-tauri/target/release/bundle/nsis/` 配下にインストーラー実行ファイル（例: `ImageMediaViewer_0.1.0_x64-setup.exe`）が生成されます。

### 5. Android APK のビルド

Android デバイス向け APK パッケージをビルドします：

```bash
# デバッグビルド (aarch64 / arm64-v8a)
npm run build:android

# リリースビルド
npm run build:android:release

# x86_64 エミュレータ向け
npm run build:android:x86_64
```

### 6. ユニットテスト・統合テストの実行

#### フロントエンド単体テスト (Vitest)
```bash
npm test
```

#### バックエンド単体・統合テスト (Rust)
```bash
cd src-tauri
cargo test
```
